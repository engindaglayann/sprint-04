Kampüs Etkinlikleri - Sprint 4

Bu proje, Kampüs Etkinlikleri uygulamasının statik HTML/JS yapısından modern bir React, TypeScript ve Vite altyapısına geçişini içermektedir.

Dosya Yapısı ve Görevleri

Projenin temel iskeletini oluşturan dosyalar ve görevleri şunlardır:

package.json: Proje adı, komutlar (dev, build) ve kullanılan paket listesini tutar.

vite.config.ts: Vite ayarlarını ve React eklentisi yapılandırmasını içerir.

index.html: Uygulamanın tek HTML dosyasıdır; içinde React'in yerleşeceği boş div#root bulunur.

src/main.tsx: React uygulamasını başlatır ve App bileşenini DOM'daki root elemanına çizer.

src/App.tsx: Uygulamanın ana bileşenidir, state yönetimi ve tüm sayfa geçişleri bu dosya üzerinden yapılır.

src/App.css: Uygulamanın tüm stil (CSS) tanımlamalarını barındırır.
